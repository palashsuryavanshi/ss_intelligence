# Docs

| Folder | Visibility | Contents |
|--------|-----------|----------|
| `docs/user/` | Public (tracked) | User-facing docs: FAQ, support, troubleshooting, privacy policy, release notes, limitations, licenses |
| `docs/internal/` | Local-only (gitignored) | Architecture notes, threat model, testing strategy, debug reports, checklists |

New internal notes go in `docs/internal/` and stay off GitHub automatically.
