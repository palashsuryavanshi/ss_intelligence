## Reporting Bugs

When reporting a bug, include:
1. Android version and device model
2. Screenshot Intelligence version
3. Steps to reproduce
4. What you expected vs what happened

**Do not attach screenshots or personal data** unless explicitly requested
and you are comfortable sharing it.

## Feature Requests

We welcome feature suggestions. Please describe:
1. What you want to do
2. Why it would be useful
3. How you currently work around the limitation

## Privacy Concerns

If you believe you've found a privacy issue:
1. Do not disclose it publicly
2. Report it via the in-app feedback channel or GitHub security advisories
3. We will investigate and respond promptly

## Response Times

- Privacy/security issues: 48 hours
- Critical bugs: 1 week
- General questions: Best effort
